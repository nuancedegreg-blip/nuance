# NuanceOS

NuanceOS est une application iOS SwiftUI qui transforme un objectif exprimé en langage naturel en plan d'action structuré.

## V1

- Saisie d'un objectif
- Analyse locale de l'objectif
- Sous-objectifs
- Informations manquantes
- Plan d'action
- Prochaine action recommandée
- Sauvegarde locale de l'historique

## Ouvrir dans Xcode

Ouvrir `NuanceOS.xcodeproj`, sélectionner un simulateur iPhone puis lancer avec `⌘R`.

## Structure

- `NuanceOS/App` : point d'entrée
- `NuanceOS/Views` : interface SwiftUI
- `NuanceOS/Models` : modèles de données
- `NuanceOS/Services` : moteur et stockage
- `NuanceOS/Resources` : ressources de l'application
